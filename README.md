# Media Downloader

A small Windows app: paste a link to a song, video or playlist (SoundCloud, YouTube and most other sites), see what it is, and save it as MP3 or MP4.

## Download

**[Download the latest version](https://github.com/Miguelgibb/media-downloader-app/releases/latest)**, then click `MediaDownloader-portable.exe` under "Assets".

## How to start

1. Double-click `MediaDownloader-portable.exe`. No installation needed.
2. If Windows shows a blue warning, click **More info**, then **Run anyway**. The app isn't signed, so Windows doesn't know it yet.
3. The first time, the app downloads its free tools (about 150 MB): yt-dlp, ffmpeg and Deno, from their official GitHub pages.
4. Paste a link and choose **Audio (MP3)** or **Video (MP4)**.

Your SoundCloud likes work too: paste `soundcloud.com/your-name/likes` (your likes must be public).

Needs Windows 10 or 11.
